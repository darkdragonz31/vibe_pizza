Menu Admin

Change what customers can order. Save stores the menu in this browser, so the order page (index.html) picks it up on the next reload in the same browser. To publish it to other browsers or devices, use Download menu-data.js and replace js/menu-data.js. Prices are in dollars.

This page has no password. Anyone who can open this folder can edit the menu.
