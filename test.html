Rule Tests

These tests check that the order page follows its business rules, like unit tests in C#. Press Run Tests after any change. A rule passes only when every test inside it passes. Manual rules have no automatic check and are listed as reminders.

Add a rule

Describe something that must always be true. Optionally add JavaScript test code so it is checked automatically; without code the rule is saved as a manual reminder.

How to write test code

Your code runs as the body of a function. These are available:

  • assert(condition, message) and assertEqual(actual, expected, message) – fail the rule when wrong.
  • OrderLogic – the order logic the page uses (see js/logic.js).
  • MENU – the live menu from the admin page. fixtureMenu() – a fixed test menu (prices in cents).
  • makeIds() – makes line ids. cartOf({ sides: { s500: 2 } }) – builds a cart quickly.
// Example: a Large pizza with no toppings costs its base price
var menu = fixtureMenu();
var cart = [];
OrderLogic.addPizzaLine(menu, cart, { size: 'L', crust: 'hand', toppings: [] }, makeIds());
assertEqual(OrderLogic.subtotal(menu, cart), 1500, 'Large base price');

Keep your rules with the project

Your rules are saved in this browser. To make them part of the project (so they are checked every time the code changes), download the file and replace js/custom-rules.js with it.
